# TipRouter Project
A thin tipping layer for Mastodon, Misskey, Concrnt, and the decentralized social web.

## what inside
- `contract/`: smart contract for ethereum
- `sui/`: smart contract for sui
- `general-tipper`: demo for tipping on the ordinary distributed-social like Mastodon, Misskey
- `tip-router-protocol.md`: protocol specification for tip-router
